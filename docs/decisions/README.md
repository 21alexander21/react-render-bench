# Architecture decisions

Use an Architecture Decision Record only for a decision that changes a durable project boundary, measurement guarantee, compatibility contract, or operational constraint.

Do not create an ADR for routine implementation choices, dependency updates, formatting, or changes that are fully explained by code and tests.

Name records with a sequence and a short subject:

```text
0001-use-same-origin-iframe.md
```

Each record should state the context, decision, consequences, and status in plain English.
